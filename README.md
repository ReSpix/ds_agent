# DS agent

ИИ-агент для генерации признаков. Задача была реализована в рамках хакатона Сбера (04.2026), описание оригинальной задачи представлено [здесь](TASK.md).

Что выполняет агент: читает датасет из папки ```data```, объединяет несколько таблиц в одну, на основе существующих признаков генерирует 5 новых, которые потом можно использовать для машинного обучения.

### Стек технологий
- Язык/Фреймворк: Python 3.10+, LangChain
- LLM: GigaChat
- Данные: pandas
- Архитектура: Agent-based pipeline, prompt engineering, code generation

### Как это работает
Агент получает датасет иp папки ```data```, в которой содержатся ```.csv``` файлы с таблицами и обязательно файл ```data/readme.txt``` с описанием задачи и структуры таблиц. Агент генерирует и выполняет python код для объединения множества таблиц в одну плоскую.

Далее агент итеративно: 
- Генерирует python код для создания новых признаков
- Обучает на их основе модель CatBoost
- Генерирует рекомендации для следующей итерации

Итерации продолжаются до достижения заданой точности модели или до лимита итераций. На каждом этапе происходит сохренение сгенерированного кода в папку ```artifacts```

### Запуск локально
**Подготовка**:
- Клонировать репозиторий
- Добавить папку ```data``` с датасетом (```.csv``` файлы таблиц и ```readme.txt``` с описанием задачи и структуры таблиц)
- Создать файл ```.env``` и добавить в него обязательные переменные (GIGACHAT_CREDENTIALS и GIGACHAT_SCOPE)


**Запуск**:
```python
python run.py
```

### Результаты
Решение успешно прошло скрытый тест Сбера: получив ранее неизвестный датасет, агент успешно создал 5 новых признаков, на которых обучение модели CatBoost дало точность 0.79

### Что можно улучшить
- Перейти от генерации кода агентом к генерации инструкций по вызову инструментов
- Более явно выделить мультиагентную составляющую: оркестратор, data engineer, ml expert, coder.
- Интегрировать lightweight-модели (например, local LLM) для offline-режима
